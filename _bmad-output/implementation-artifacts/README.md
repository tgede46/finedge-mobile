# Suivi d'implémentation mobile — FinEdge (`findge`)

Chaque story a **son dossier**. Dedans, toujours les mêmes 3 fichiers :

| Fichier | Sens |
| :--- | :--- |
| `deja-fait.md` | Ce qui est déjà livré dans le code |
| `en-cours.md` | Ce qu'on est en train de faire maintenant |
| `a-faire.md` | Ce qui reste / ce qui va être fait |

Plus `README.md` : titre, statut, fichiers code concernés.

**Règle code** : les composants UI réutilisables vont dans `lib/widgets/`. Les fichiers de `lib/views/` restent des écrans courts.


Ce dépôt ne suit que le **mobile**. Backend (story 4.2) et admin (épic 5) ne sont pas documentés ici.
